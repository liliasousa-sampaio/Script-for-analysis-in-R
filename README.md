# Data and scripts – Human disturbances and woody flora diversity

The data made available in this repository are part of the study “Human Disturbances and Woody Flora Diversity Along a Caatinga-Brejo Altitudinal Gradient in Northeastern Brazil,” published in the journal Biotropica.

The spreadsheet “Planilhas utilizadas nas análises.xlsx” contains the data used for the analyses in the article, including species abundance data, environmental and spatial variables, taxonomic and phylogenetic diversity metrics at alpha and beta scales, and the species identification matrix.

These data were used to perform the analyses presented in the article. The file “Script_R.R” contains the packages and code used for the main analyses, including multi-model analysis, Principal Component Analysis (PCA), and Non-metric Multidimensional Scaling (NMDS).

All analyses were performed in R version 4.3.3 (R Core Team, 2024).
